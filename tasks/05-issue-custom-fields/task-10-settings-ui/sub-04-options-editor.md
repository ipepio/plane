# Sub-04 — Editor de opciones

**Task:** 10 · **Tamaño:** M

## Cambio

Componente reutilizable que permite:
- Listar opciones (sortable DnD).
- Crear nueva opción inline (name + color picker).
- Editar inline.
- Borrar (con confirm).
- Toggle `is_active`.

Persiste cada cambio inmediatamente via service.

## Aceptación

- [ ] Drag reordena y guarda.
- [ ] Borrar pide confirm.
- [ ] Color picker con paleta limitada (10 colores).
